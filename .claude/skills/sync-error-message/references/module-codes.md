# Module codes

The module code is the third part of an error code (`E-0-<MODULE>-<n>`) and the top-level key in `src/i18n/en-error.json`. It identifies the module or feature scope, and is 2 to 3 uppercase letters.

| :- | :- |
| GEN | General errors, such as Unauthenticated or Unauthorized |
| WK | My Work |
| MDA | TESSR Review |
